LIMO Assembly Simulator

A small browser-based simulator for the LIMO ISA: Sesotho instructions and registers

Assembly program

Write one instruction per line. Labels end with a colon. Use # for comments. Register names can be x0–x31 or their LIMO Sesotho names.

Ready. Press Run program or Step.

Machine code

Fields, left to right: funct7 or imm · rs2 · rs1 · funct3 · rd · opcode (colours are only a visual aid; the field order is the same in every row). "NEXT" marks the instruction that runs next.

Supported instructions

  • kopanya rd, rs1, rs2 — add
  • tlosa rd, rs1, rs2 — subtract
  • eketsa rd, rs1, imm — add immediate
  • kapa rd, rs1, rs2 — OR
  • le rd, rs1, rs2 — AND
  • suthumetsa rd, rs1, shamt — shift left
  • bofa rd, imm(rs1) — load word
  • boloka rs2, imm(rs1) — store word
  • lekana rs1, rs2, label — branch if equal
  • ekholo rs1, rs2, label — branch if signed ≥
  • qhoma rd, imm(rs1) — jump via register
  • bofahh rd, imm — pseudoinstruction
  • chechisa rd, rs — pseudoinstruction
